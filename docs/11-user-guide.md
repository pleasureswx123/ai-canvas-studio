# AI Canvas Studio 用户使用手册

这份文档写给第一次使用系统的人。你不需要懂代码，只需要按步骤操作，就可以用它完成一次 AI 图片/视频创作。

## 这个系统是做什么的？

AI Canvas Studio 是一个“AI 创作画布”。你可以把它理解成一个用于整理创意、素材、提示词、图片和视频生成结果的工作台。

它不是单纯的聊天工具，也不是只生成一张图片的工具。它更像一个可视化创作桌面：

- 你可以创建一个工程，保存一次创作任务。
- 你可以在画布上放图片节点、视频节点、文本节点。
- 你可以上传本地素材。
- 你可以把文字、图片、视频节点连接起来，表达“这个内容要参考那个内容”。
- 你可以用 AI 生成图片或视频。
- 生成结果会自动保存到当前工程里，后续可以继续复用。
- 常用素材可以保存到素材库，下次直接拖回画布。

## 它解决用户什么问题？

很多 AI 创作流程会变得混乱：

- 提示词散落在聊天记录里。
- 图片版本太多，不知道哪张图对应哪个想法。
- 视频生成要参考首帧、尾帧、上游图片，很容易搞错。
- 素材、历史结果、工程文件到处都是。
- 做到一半刷新页面，东西可能丢失。

AI Canvas Studio 解决的是“创作过程可视化、可保存、可复用”的问题。

它把创作过程变成一个画布：

- 文本节点记录想法和提示词。
- 图片节点保存参考图和生成图。
- 视频节点保存视频生成参数和结果。
- 连线表示参考关系。
- 工程负责保存这一次创作的全部内容。
- 素材库负责保存长期复用的素材。

## 适合谁使用？

适合这些用户：

- 想用 AI 做图片创作的人。
- 想用图片生成视频的人。
- 想把提示词、参考图、生成结果组织起来的人。
- 想做多版本创意探索的人。
- 不想把素材和生成历史弄丢的人。

暂时不适合：

- 只想一句话快速生成一张图、不需要管理过程的人。
- 需要多人协作、账号权限、云端部署的人。
- 需要专业视频剪辑时间线的人。

这些能力后续可以继续扩展。

## 使用前你需要知道的 5 个概念

### 1. 工程

工程就是一次创作项目。比如：

- “短视频广告 A”
- “产品主图设计”
- “角色设定探索”
- “AI 视频分镜”

一个工程里会保存画布节点、连线、素材和生成历史。

### 2. 画布

画布是中间的大区域。你可以在这里放节点、移动节点、连接节点。

### 3. 节点

节点是画布上的一个创作单元。

目前主要有三种：

- 图片节点：放参考图、生成图片、裁剪图片、标注图片。
- 视频节点：生成视频、设置首帧/尾帧、设置视频参数、剪辑视频。
- 文本节点：记录想法、提示词、说明，也可以作为上游文本参考。

### 4. 连线

连线表示“参考关系”。

例如：把文本节点连到图片节点，表示图片生成时可以参考这段文本。把图片节点连到视频节点，表示视频生成时可以参考这张图片。

### 5. 素材库

素材库是长期保存素材的地方。你可以把常用图片或视频保存到素材库，以后拖回任何工程继续使用。

## 第一次使用：从 0 完成一次创作

下面是一条最基础的使用路径。

### 第一步：打开系统

开发环境启动后，在浏览器打开：

```text
http://127.0.0.1:5174
```

如果你不是开发人员，只需要让技术同事启动好系统，然后给你这个地址。

### 第二步：新建工程

点击左侧的“新建工程”。

系统会弹出工程名称输入框。输入一个容易识别的名称，例如：

```text
电商产品视频测试
```

点击“创建”。

创建成功后，中间画布会进入可编辑状态。

### 第三步：添加文本节点

点击顶部工具栏的“文本”。

画布中会出现一个文本节点。你可以在里面写创作想法，例如：

```text
一款高级感白色香薰产品，干净背景，柔和自然光，适合电商主图。
```

这个文本节点可以作为后续图片或视频生成的参考。

### 第四步：添加图片节点

点击顶部工具栏的“图片”。

画布中会出现一个图片节点。你可以在图片节点中输入图片生成提示词，设置模型、比例、尺寸、质量等参数。

如果你已经有本地参考图，也可以点击顶部“上传”，选择本地图片。上传后系统会自动在画布上创建一个图片节点。

### 第五步：连接节点

如果你希望图片生成参考某段文本，可以从文本节点拖一条线连接到图片节点。

这条线表示：

```text
图片节点生成时，可以参考文本节点内容
```

如果你希望视频生成参考某张图片，可以把图片节点连接到视频节点。

### 第六步：生成图片

在图片节点中填写提示词和参数，然后点击生成按钮。

生成过程大致是：

1. 前端把提示词和参数提交给媒体服务。
2. 媒体服务调用已配置的图片 AI provider。
3. 图片生成成功后保存到当前工程 assets。
4. 图片节点自动显示生成结果。
5. 工程自动保存。

如果当前使用 mock provider，系统会返回模拟结果，适合本地测试。如果配置了真实 API key，则会调用真实模型。

### 第七步：保存图片到素材库

如果某张图后续还会用到，可以在图片节点里点击保存素材。

保存时填写：

- 素材名称
- 分类
- 类型

保存后，它会出现在右侧素材库中。

### 第八步：添加视频节点

点击顶部工具栏的“视频”。

画布中会出现一个视频节点。你可以输入视频提示词，设置模型、场景、比例、分辨率和时长。

如果视频需要参考图片，可以把图片节点连接到视频节点。

### 第九步：设置首帧/尾帧

如果视频节点连接了上游图片，视频节点中可以选择首帧或尾帧参考。

常见用法：

- 首帧：视频从这张图开始。
- 尾帧：视频最后接近这张图。

这样可以让视频生成更稳定，也更接近你的创作意图。

### 第十步：生成视频

在视频节点中点击生成。

视频生成一般不是立即完成，而是任务模式：

1. 提交视频任务。
2. 系统显示任务状态。
3. 前端自动轮询任务进度。
4. 成功后视频保存到当前工程 assets。
5. 视频节点显示结果。

如果失败，系统会显示错误信息。工程数据不会因为生成失败而损坏。

### 第十一步：查看历史记录

工程会保留最近的图片/视频生成历史。

你可以从历史中找回之前的结果，并拖回画布继续使用。

### 第十二步：保存和重新打开

系统支持自动保存，也可以手动点击保存。

刷新页面后，你可以在左侧工程列表重新打开工程。画布上的节点、连线、素材引用会恢复。

## 常用操作说明

### 新建工程

用于开始一次新的创作。建议工程名称写清楚用途。

### 打开工程

从左侧工程列表点击工程名称，即可打开旧工程继续编辑。

### 重命名工程

用于修改工程名称，不会删除工程内容。

### 删除工程

会删除本地工程数据和工程 assets。删除前系统会二次确认。

### 上传素材

点击顶部“上传”，选择图片或视频文件。系统会把文件保存到当前工程 assets，并创建对应节点。

### 保存素材

把当前工程里的图片或视频保存到全局素材库，方便之后复用。

### 拖入素材

从右侧素材库拖素材到画布，可以快速创建图片或视频节点。

### 复制节点

选中节点后点击复制，可以基于已有节点快速创建变体。

### 删除节点

选中节点后点击删除，会移除节点以及相关连线。

## 一个典型案例：用一张产品图生成短视频

第一步：新建工程，命名为：

```text
香薰产品短视频
```

第二步：上传产品图。

第三步：系统自动生成图片节点。

第四步：添加文本节点，写视频创意：

```text
镜头缓慢推进，产品放在干净桌面上，阳光从侧面照入，整体高级、安静、有质感。
```

第五步：添加视频节点。

第六步：把产品图片节点和文本节点连接到视频节点。

第七步：在视频节点里选择产品图作为首帧。

第八步：设置视频比例、分辨率和时长。

第九步：点击生成视频。

第十步：等待任务完成，查看生成结果。

第十一步：如果满意，把结果保存到素材库；如果不满意，复制视频节点修改提示词再生成一个版本。

## 数据会保存在哪里？

系统会把工程数据保存在本机目录：

```text
projects/<工程编号>/project_data.json
projects/<工程编号>/assets/
```

素材库数据保存在：

```text
material-library/library_data.json
material-library/assets/
```

你不需要手动编辑这些文件。正常使用时，通过界面操作即可。

## API key 和 AI 模型对普通用户意味着什么？

如果系统使用 mock provider，你可以体验流程，但不会调用真实模型。

如果要真实生成图片或视频，需要管理员或技术同事在 `.env.local` 中配置 API key。

普通用户不需要在页面里输入 API key，也不应该把 key 粘贴到浏览器里。所有真实模型调用都在后端完成。

## 常见问题

### 为什么我点击生成后没有真实图片或视频？

可能当前使用的是 mock provider，或者真实模型 API key 没有配置。联系管理员检查 `.env.local` 和 `npm run env:check`。

### 为什么视频生成要等一会儿？

视频生成通常是异步任务。系统需要先提交任务，再轮询进度，成功后下载结果。

### 刷新页面会丢内容吗？

正常不会。系统有自动保存，也可以手动保存。刷新后从左侧工程列表重新打开即可。

### 删除工程后还能恢复吗？

删除工程会移除本地工程数据。删除前要确认不再需要。重要工程建议先备份。

### 素材库和工程 assets 有什么区别？

工程 assets 属于某一个工程。素材库是全局复用区，可以跨工程使用。

### 我可以不用连线吗？

可以。连线只是表达参考关系。简单创作可以直接在单个节点里写提示词生成。

### 我可以一个工程里做多个版本吗？

可以。建议复制节点，修改提示词或参数，生成多个版本进行对比。

## 推荐使用习惯

- 一个明确目标建一个工程。
- 文本节点写清楚创意和要求。
- 图片节点保存关键参考图。
- 视频节点只放和视频生成相关的信息。
- 用连线表达参考关系。
- 满意的结果保存到素材库。
- 做不同版本时复制节点，不要直接覆盖旧思路。

## 最短上手路径

只记住这 6 步也可以开始：

1. 新建工程。
2. 上传图片或添加文本节点。
3. 添加图片或视频节点。
4. 用连线连接参考内容。
5. 点击生成。
6. 保存满意结果到素材库。
